# Apostila da API de Integração PNCP

Versão publicada: https://vinit2hs.github.io/apostila-api-pncp/

Manual de Integração 2.6. A página é o arquivo `index.html`.

Para publicar uma edição nova, a partir desta pasta:

```bash
cp "Apostila_API_PNCP_Comentada (1).html" index.html
git add index.html
git commit -m "Atualiza a apostila"
git push
```

O mesmo endereço passa a servir a versão nova cerca de um minuto depois do push.
